# 介绍

欢迎使用 **全景智能 OA 协同办公平台**！

## 什么是全景智能 OA

全景智能 OA 是一个企业级协同办公平台，提供审批流程、工作流管理、组织架构管理等功能。

## 主要特性

- 📝 **动态表单引擎** - JSON Schema 驱动的表单渲染
- 🔗 **工作流引擎** - 可视化流程设计器
- 🔒 **权限管理** - RBAC 权限模型
- 📊 **数据可视化** - ECharts 图表集成
- 📁 **文档管理** - PDF/Excel 文件处理

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.x | 渐进式 JavaScript 框架 |
| TypeScript | 5.x | JavaScript 的超集 |
| Vite | 5.x | 下一代前端构建工具 |
| Pinia | 2.x | Vue 官方状态管理 |
| Vue Router | 4.x | Vue 官方路由 |
| Element Plus | 2.x | Vue 3 UI 组件库 |
| Tailwind CSS | 3.x | 实用优先的 CSS 框架 |
