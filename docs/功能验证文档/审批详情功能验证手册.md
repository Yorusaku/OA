## 🔍 常见问题

### Q1: 页面空白怎么办?
**A**: 按 F12 打开开发者工具,查看 Console 是否有错误信息。

### Q2: 表单不显示怎么办?
**A**: 检查节点权限配置 `nodePermissions`,确认字段权限未全部设为 `hidden`。

### Q3: 按钮不响应怎么办?
**A**: 检查 `dynamicFormRef` 是否正确获取,在控制台输入 `dynamicFormRef.value` 查看。

### Q4: 时间显示不正确?
**A**: 这是 Mock 数据,时间固定为 2026-02-26,实际开发中会从 API 获取。

### Q5: 如何修改 Mock 数据?
**A**: 编辑 `useApprovalDetail.ts` 文件的 `queryFn` 函数,修改返回的对象。
