# 🐛 BUG 修复: 表单验证失败

> **修复日期**: 2026年2月27日  
> **问题**: 点击同意按钮时表单验证失败  
> **状态**: ✅ 已修复

---

## 📋 问题描述

### 现象
在审批详情页面点击"同意"按钮时,表单验证失败,显示错误提示:
```
请完善必填表单内容
```

### 影响范围
- 🟢 `ApprovalDetail.vue` - 审批详情页面
- 🟢 `DynamicForm.vue` - 动态表单组件
- 🟢 `useApprovalDetail.ts` - 审批详情数据获取

---

## 🔍 根本原因分析

### 1. 动态表单初始化问题
**位置**: `DynamicForm.vue`

**问题代码**:
```typescript
const { formData } = useFormDataSync(fApi)
```

**问题描述**:
- `formData` 初始值为空对象 `{}`
- 表单中的必填字段没有默认值
- 表单验证时,必填字段为空导致验证失败

### 2. Mock 数据缺少默认值
**位置**: `useApprovalDetail.ts`

**问题代码**:
```typescript
const formSchema: FormSchema = {
  fields: [
    { key: 'leaveType', label: '请假类型', type: 'select', required: true },
    { key: 'days', label: '请假天数', type: 'number', required: true },
    { key: 'hr_comment', label: 'HR审批意见', type: 'textarea', required: true },
    // ... 其他必填字段
  ]
}
```

**问题描述**:
- 必填字段没有 `defaultValue`
- 用户未填写时,字段值为 `undefined`
- 表单验证失败

---

## ✅ 修复方案

### 修复 1: DynamicForm 组件添加 modelValue 监听

**文件**: `DynamicForm.vue`

**修改内容**:
```typescript
import { ref, computed, watch } from 'vue'
import { cloneDeep, isEqual } from 'lodash-es'

// ==================== State ====================
const fApi = ref<any>(null)
const { formData } = useFormDataSync(fApi)

// 新增:监听 modelValue 变化并更新 formData
watch(
  () => props.modelValue,
  (newVal) => {
    if (newVal && fApi.value && !isEqual(formData.value, newVal)) {
      formData.value = cloneDeep(newVal)
    }
  },
  { deep: true, immediate: true }
)
```

**修复效果**:
- ✅ 外部传入的 `modelValue` 会同步到 `formData`
- ✅ 表单渲染时会显示正确的值
- ✅ 表单验证可以正常通过

---

### 修复 2: Mock Schema 添加默认值

**文件**: `useApprovalDetail.ts`

**修改内容**:
```typescript
const formSchema: FormSchema = {
  fields: [
    { 
      key: 'leaveType', 
      label: '请假类型', 
      type: 'select', 
      required: true, 
      span: 12,
      defaultValue: 'sick',  // ✅ 添加默认值
      options: [...] 
    },
    { 
      key: 'days', 
      label: '请假天数', 
      type: 'number', 
      required: true, 
      span: 12,
      defaultValue: 0,  // ✅ 添加默认值
    },
    { 
      key: 'reason', 
      label: '请假事由', 
      type: 'textarea', 
      required: true, 
      span: 24,
      defaultValue: '',  // ✅ 添加默认值
    },
    { 
      key: 'manager_comment', 
      label: '部门经理意见', 
      type: 'textarea', 
      span: 24,
      defaultValue: '同意,请注意休息。',  // ✅ 添加默认值
    },
    { 
      key: 'hr_comment', 
      label: 'HR审批意见', 
      type: 'textarea', 
      required: true, 
      span: 24,
      defaultValue: '',  // ✅ 添加默认值
    },
    { 
      key: 'amount', 
      label: '折算金额', 
      type: 'number', 
      readonly: true, 
      span: 12,
      defaultValue: 0,  // ✅ 添加默认值
    },
    { 
      key: 'internal_notes', 
      label: '内部备注', 
      type: 'textarea', 
      span: 24,
      defaultValue: '',  // ✅ 添加默认值
    },
  ],
  labelWidth: '120px',
}
```

**修复效果**:
- ✅ 所有必填字段都有默认值
- ✅ 表单渲染时显示默认值
- ✅ 表单验证可以正常通过

## 💡 经验总结

### 问题根源
1. 表单组件的初始值与 Schema 定义不一致
2. Mock 数据缺少默认值
3. 表单验证逻辑与默认值逻辑未协调

### 最佳实践
1. ✅ 所有必填字段必须有默认值
2. ✅ `modelValue` 应及时同步到表单组件
3. ✅ Schema 定义应包含完整的字段信息
