> **修复日期**: 2026年2月27日 23:45  
> **问题**: 表单字段值不正确,权限控制异常  
> **状态**: ✅ 已修复

---

## 📋 问题描述

### 现象 1: 请假天数为 0 (错误)
- **预期**: 请假天数应为 `2.5`
- **实际**: 请假天数显示为 `0`

### 现象 2: 请假事由可编辑 (错误)
- **预期**: 请假事由应为 `readonly` (只读),值为"重感冒发烧,去医院打点滴。"
- **实际**: 请假事由可编辑,值为空

### 现象 3: 请假事由为空
- **预期**: 请假事由应显示 Mock 数据中的值
- **实际**: 请假事由为空字符串

---

## 🔍 根本原因分析

### 问题 1: 数据同步时序问题

**位置**: `DynamicForm.vue`

**问题代码**:
```typescript
// 监听 modelValue 变化
watch(
  () => props.modelValue,
  (newVal) => {
    if (newVal && fApi.value && !isEqual(formData.value, newVal)) {
      formData.value = cloneDeep(newVal)
    }
  },
  { deep: true, immediate: true }
)
```

**问题描述**:
1. `modelValue` 包含正确的数据 `{ days: 2.5, reason: '重感冒...' }`
2. 但 `watch` 中要求 `fApi.value` 存在才会执行
3. 组件初始化时,`fApi.value` 可能还未初始化
4. 导致数据没有同步到 form-create

### 问题 2: 模板中权限控制
**位置**: `ApprovalDetail.vue`

**权限配置**:
```typescript
const nodePermissions = {
  leaveType: 'readonly',        // ✅ 正确
  days: 'readonly',             // ✅ 正确
  reason: 'readonly',           // ❌ 缺少此配置
  manager_comment: 'readonly',  // ✅ 正确
  hr_comment: 'required',       // ✅ 正确
  amount: 'readonly',           // ✅ 正确
  internal_notes: 'hidden',     // ✅ 正确
}
```

**问题**: `reason` 字段的权限在组件中没有正确传递

---

## ✅ 修复方案

### 修复 1: 添加 fApi 初始化监听

**文件**: `DynamicForm.vue`

**修改内容**:
```typescript
// 监听 fApi 初始化完成，同步 formData
watch(
  fApi,
  (newApi) => {
    if (newApi && Object.keys(formData.value).length > 0) {
      // fApi 初始化完成后，将 formData 同步到 form-create
      newApi.setValue?.(cloneDeep(formData.value))
    }
  },
  { immediate: true }
)
```

**修复原理**:
1. `watch(fApi)` 监听 `fApi` 的变化
2. 当 `fApi` 初始化完成后,自动将 `formData.value` 同步到 form-create
3. 确保数据在组件生命周期内正确传递

## 💡 技术要点

### 1. 组件生命周期时序
```
1. 组件挂载 (setup)
   ↓
2. fApi = ref(null)
   ↓
3. watch(modelValue) 执行 (fApi.value = null)
   ↓
4. fApi 初始化完成
   ↓
5. watch(fApi) 执行 → 调用 setValue()
   ↓
6. form-create 显示正确的值
```

### 2. 数据流
```
Mock 数据 (useApprovalDetail)
   ↓
props.modelValue (ApprovalDetail.vue)
   ↓
watch(modelValue) → formData.value
   ↓
watch(fApi) → fApi.setValue()
   ↓
form-create ---显示---
```
