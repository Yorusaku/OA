# 演示脚本：OA 企业级治理能力演示（15-20 分钟）

## 演示目标
展示从"发起审批"到"流程治理"到"审计追溯"的完整企业级闭环。

## 场景设定
- 角色：管理员（admin / admin123）
- 流程：请假审批流程

## 演示步骤

### 第1幕：登录与首页（2分钟）
1. 打开 OA 系统，使用 admin 账号登录
2. 进入工作台，查看待办数量、统计面板
3. 【可讲点】说明系统支持审批协同（会签/或签）、SLA 超时升级、代理机制

### 第2幕：流程治理——创建与发布（5分钟）
1. 进入"流程管理"页 → 点击"新建流程"
2. 使用流程编辑器拖拽节点（开始→审批→结束）
3. 保存后返回列表，状态为"草稿"
4. 点击"影响分析"按钮 → 展示风险等级（低风险，影响0个审批）
5. 点击"发布"按钮 → 确认后发布成功，状态变为"启用"
6. 【可讲点】说明发布前影响分析的价值：展示关联审批数量和风险等级

### 第3幕：发起审批与处理（4分钟）
1. 进入"发起审批"页 → 选择请假流程，填写表单
2. 提交后进入"我的待办"，查看新审批单
3. 点击"同意"完成审批
4. 【可讲点】说明审批协同机制（and/or 模式）和 SLA 升级逻辑

### 第4幕：版本管理与回滚（4分钟）
1. 回到流程管理页，编辑刚发布的流程（如修改节点配置）
2. 点击"版本历史" → 展示所有版本记录（包含操作人、时间、状态）
3. 点击"回滚" → 展示版本列表，选择目标版本
4. 看到风险提示，点击"确认回滚"
5. 【可讲点】说明回滚策略：版本可选 + 风险提示 + 操作确认，避免盲回滚

### 第5幕：审计追溯闭环（3分钟）
1. 进入"审计日志"页
2. 筛选条件：按模块（审批/工作流）、动作（发布/回滚）筛选
3. 点击某条审计记录 → 查看详情（操作人、IP、UserAgent、耗时、关联对象）
4. 点击关联对象链接 → 跳转到对应审批单或流程编辑器
5. 【可讲点】从审计日志可以直接串联到业务对象，面试时可现场验证整体链路
6. 导出 CSV → 展示数据可交付性

### 第6幕：总览与总结（2分钟）
1. 回顾完整链路：新建流程→发布→影响分析→发起审批→处理→版本回滚→查审计
2. 强调技术栈：Monorepo（pnpm + turbo）、Vue 3 + LogicFlow、Fastify BFF
3. 强调个人贡献：审计模型设计、流程版本治理、前端体验闭环

## 关键话术

### 面试官可能追问及应对

**Q: 为什么采用统一审计事件模型？**
A: （参考 ADR-002）单一 AuditEvent 模型让跨模块关联追踪一目了然，避免了分表查询的复杂性。

**Q: 回滚策略为什么是"版本可选"而非"一键回滚"？**
A: （参考 ADR-003）企业治理要求可解释、可追溯。展示版本历史 + 风险提示 + 操作确认是"可信度"的关键。

**Q: 审计日志能关联到具体业务对象吗？**
A: 每条审计事件携带 `links` 字段，可直接跳转到审批单详情或流程编辑器。

**Q: 如何保证生产环境可用？**
A: CI 门禁包含 lint + typecheck + test + build 四项检查，所有关键路径有单元测试和集成测试覆盖。
